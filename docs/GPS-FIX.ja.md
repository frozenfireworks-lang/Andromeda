# Andromeda v2.5.2 日本のGPS位置ズレ修正

## 原因と修正

基点: v2.5.2 (`ad7a9413551f6a5a0f6504f8ea43dbec6290a189`)。
`CoordTransform.isOutOfChina` は経度72.004～137.847、緯度0.8293～55.8271という長方形で判定していたため、名古屋が中国向け変換の対象になっていました。
旧式を数値再現すると名古屋駅(35.170900, 136.881500)は(35.17120136, 136.87618594)となり、約483m西へ移ります。東京駅は元から長方形の外でした。

- 中国向け補正は初期値OFF。日本ではOFFのまま使用してください。
- 補正ONでも、日本の座標は変換しません。中国の陸域ポリゴンで変換対象を限定します。
- 地図タップ・住所検索・MapKit経路の入力時だけ補正し、内部・保存・位置出力はWGS-84に統一しました。
- お気に入り・アプリプロファイルは保存したWGS-84をそのまま再利用し、再変換しません。地図表示用に作った座標を保存値へ書き戻しません。
- ジョイスティックはWGS-84上で移動し、そのまま出力します。
- GPXはWGS-84の全経路点を維持します。旧実装は先頭と末尾からMapKit経路を再検索していました。
- 自動移動の速度・倍率・一時停止を維持し、経路補間を共通化して短い線分が続く場合の距離繰越をテストしました。
- 既存画面を維持し、設定のLocSim欄に「中国向け座標補正」を追加しました。

### 座標処理の監査

| 経路 | 保存/シミュレーション | 変換境界 |
|---|---|---|
| 地図タップ | WGS-84 | mapToWGS84で必要時に1回 |
| 住所検索 | WGS-84 | mapToWGS84で必要時に1回 |
| お気に入り/プロファイル | WGS-84 | 出力時変換なし、表示時のみコピーを変換 |
| 旧ブックマーク/共有拡張 | 既存の保存座標 | 出力時変換なし（既存挙動） |
| MapKitルート | 入力頂点をWGS-84へ正規化後に補間 | ルート選択時のみ |
| GPX | WGS-84 | 出力時変換なし |
| ジョイスティック | WGS-84 | 出力時変換なし |

中国向け補正は座標系の自動検出ではありません。GCJ-02地図が実際に使われる場合だけ有効にしてください。国境・海岸付近の判定はNatural Earth 1:110mの概略データで、厳密な行政境界ではありません。香港・マカオを追加除外し、台湾・日本は変換対象外です。小島や境界付近では補正対象から外れる可能性があります。

旧版で既にずれた状態で保存されたお気に入りは自動移行しません。座標の由来を判別できないため、地図で選び直して保存してください。
自動ルートには既存の約1mのランダムな位置揺らぎが残ります。地図タップ自体にはこの揺らぎはありません。

## 自動検証

macOSで `swift test` を実行します。アプリと同じSwiftソースをコンパイルし、名古屋・東京・日本各地・中国の既知座標・補正OFF・GPX中間点・不正GPX・経路補間・速度を検証します。
Windows上での数値再現はSwift実行や実機試験の代わりではありません。

## ビルド

GitHub Actionsの `TrollStore TIPA` を使用します。専用ブランチへのpushで実行されます。
Xcode 16.2、macOS 14、固定コミットのTheosとiPhoneOS14.5 SDKでRootHelperをソースから再ビルドします。アプリはXcodeのiPhoneOS SDKでReleaseビルドします。
Apple Developerの証明書を使わず、元のアプリ・共有拡張・RootHelperのentitlementsをldidで保持します。
梱包前にarm64、実行権限、entitlementsの完全一致、iOS16対応のMinimumOSVersion、再ビルドしたRootHelperの同梱を検査します。
ArtifactsにTIPA、SHA256SUMS、ログを保存します。公開Releaseは作成しません。

## TrollStoreへのインストールと実機確認

1. 成功したActions実行のArtifactsから `Andromeda-v2.5.2-japan-gps` をダウンロードし、ZIPを展開します。
2. `Andromeda-v2.5.2-japan-gps.tipa` をiPhoneに保存します。
3. TrollStoreの「+」からTIPAを選択し、Installします。既存アプリと同一IDなので置換になります。必要なお気に入りは事前に控えてください。
4. Andromedaの設定で「中国向け座標補正」がOFFであることを確認します。
5. 名古屋駅(35.170900,136.881500)、東京駅(35.681236,139.767125)をそれぞれ選択し、位置を参照する別アプリでも確認します。
6. お気に入りの保存・再選択を複数回行い、位置が変わらないことを確認します。
7. ジョイスティック各速度、ルート速度倍率、一時停止・再開、GPX中間点を確認します。
8. 終了後は停止操作で位置シミュレーションを解除してください。

実機のiOS16＋Dopamine＋TrollStoreでのインストール・実測は別途必要です。CI成功は実機動作の保証ではありません。
